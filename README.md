# Automated Aeroponics System 🌱

## Overview
This project focuses on building a **simple, low-cost, and automated aeroponics system** suitable for students and small-scale farmers.  
The aim is to grow plants without soil using nutrient mist, while saving water and reducing resource waste.

## Why Aeroponics?
- Uses up to **90–98% less water** than soil farming
- Faster plant growth due to direct oxygen exposure to roots
- Minimal land requirement
- Suitable for urban and rural use

## Key Features
- Soil-less plant growth using fine nutrient mist
- Automated misting cycle (timer-based)
- Water recirculation system
- Low power consumption
- Scalable vertical design

## Innovation Aspect
Unlike industrial aeroponics, this system focuses on:
- **Affordability**
- **Ease of use**
- **Student-friendly design**
- Potential integration with carbon-saving concepts

## Target Users
- Students & schools
- Small farmers
- Urban growers
- Science competitions & exhibitions
